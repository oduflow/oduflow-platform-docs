# Visitor and integrator guide

The guide is maintained as the English [Odubook manual](https://github.com/oduflow/oduflow-platform/blob/main/addons/odubook/data/manuals/integrator-guide-en.md).

In a control environment with the manual installed, internal users can open **Odubook → Manuals** and
select **Oduflow: a guide for visitors and integrators**. The shelf requires an
internal Odoo account; partner portal membership alone does not grant access.

Installation seeds the manual once. Later module upgrades preserve administrator
edits; update the existing English version through the Manuals upload workflow
when publishing a revised guide.

For public operating guides, start with [partner access](partner-access.md),
[customer configuration](customer-configuration.md) and [client access](client-access.md).
The internal manual and this public site have different publication workflows.
